练薄肌交给 AI

一个记吃饭和训练的网页，装在你自己的服务器上。拍张饭的照片，Claude 帮你估热量。练完一组打个勾，它告诉你下次该用多重。每天它会把你的记录过一遍，写个日报。

看代码怎么装

代码都在 GitHub 上。AI 那部分用的是你自己的 Claude 账号。

能干什么

拍照记饭

  • 饭前拍一张，吃剩的再拍一张，热量按真正吃进去的算
  • 估得不对就点「估高了」或「估低了」，下次同一道菜它会记得
  • 看不出是肥肉还是豆干的时候，它会直接问你

边练边记

  • 每组下面写着上次做了多少，这次的重量已经帮你填好
  • 组间休息有倒计时，锁屏了也会提醒
  • 想接递减组，点一下就行
  • 戴着 Apple Watch 练，心率会自动对到这次训练上

计划自己定

  • 几个训练日、按什么顺序轮、一周练哪几天，都是你自己排。删错了能撤销
  • 加不加重有固定的规则。每组都做到次数上限就加一档，连着三次没长进会提醒你换个练法

有事跟 Claude 说

  • 比如「这周出差，只能练 3 天」。它下次处理的时候照着改，改完回你一句
  • 大的改动它只提建议，你点了同意才算。小调整它会直接改，不满意可以撤回
  • 说话风格有三种：正经教练、抽象搭子、毒舌教练

看身体变化

  • 体重、围度、睡眠、静息心率、步数，都能看 7 天、30 天、90 天的曲线
  • 每张图上有 Claude 写的一句看法和一条建议
  • 睡眠、步数、体重可以从 Apple 健康自动同步过来

自己装一个

要一台能跑 Python 3.9 的机器，再加一个 Claude 账号。没有要装的依赖。

先在电脑上试试

git clone https://github.com/ffanyt/boji-lab.git
cd boji-lab
LSJ_TOKEN=dev-token LSJ_PASSWORD=dev-password \
LSJ_DATA=./data LSJ_COOKIE_SECURE=0 \
python3 app/server.py

打开 http://127.0.0.1:8780，用 admin 和上面的密码登录。要放到服务器上，看 deploy/README.md。

接上 Claude Code

# 按 docs/config.example.json 写服务器地址和令牌
mkdir -p ~/.config/lianshiji
bin/lsj users      # 能连上就对了
claude             # 再输入 /fitness-review

在网页的「我的 → 基础信息」里填好身高体重和目标，再跑 /fitness-plan，它会给你出个计划。想让它每天自己跑，用 scripts/auto-review.sh。

放到手机上

用 Safari 打开你的网址，点分享，选「添加到主屏幕」。以后从图标打开就是全屏的，也能收通知。

睡眠、步数、体重想自动同步的话，去「我的 → Apple 健康同步」下载快捷指令，把你的同步令牌贴进去。

朋友也想用，就在「我的 → 用户管理」里发个邀请链接，每个人的记录是分开的。
