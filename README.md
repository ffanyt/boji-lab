# 薄肌研究所

[English](README.en.md)

一个自己部署的饮食和训练记录网页，分析交给你电脑上的 Claude Code：用数据练薄肌，研究员是 AI。

吃饭前后拍张照、练完记几组、早上称个体重，都在手机网页上点几下。服务器只负责存。你电脑上的 Claude Code 当你的私人教练：定时（或者你叫它的时候）运行 `/fitness-review`，把新记录拉下来，看照片估热量和三大营养素，点评训练、给出下次的重量，写日报和周报，办你在网页上交代的事，按你给的授权调整计划，再写回服务器。手机上打开就能看到。

## 它是怎么转的

```
 手机浏览器 ──记录、照片、留言──▶  你的服务器（app/server.py）  ◀──读取、写回──  你电脑上的 Claude Code
   （网页）   ◀──简报、提案────   SQLite + 照片目录              （bin/lsj）      /fitness-review、/fitness-plan
                                                                                 （可以用 launchd 定时跑）
                                   ▲
 iPhone 快捷指令「同步健康」───────┘  睡眠、步数、活动能量、静息心率、HRV、体重、体脂率、心率明细（只能上传）
```

- 服务器不调用任何模型接口，只是一个只用 Python 标准库的小程序。会连外网的只有可选的训记对接（「从训记同步」「写进训记」两个按钮）
- 分析是离线、批量的：定时任务或者你运行 Claude Code 的时候出结果。不需要实时
- 多人共用一台服务器：每人一个账号，记录、照片、计划、报告按账号分开；Claude 一个账号一个账号地处理。管理员发邀请链接，朋友自己注册，第一次打开有新人引导（知情同意、填资料、选风格和人设、加到主屏幕、开通知）；每个人都能自己导出和注销

## 功能

- **饮食**：拍照记一餐（饭前、饭后各一张），写吃了多少、饱不饱、饭后感受。Claude 按照片逐样估热量和蛋白质、碳水、脂肪，扣掉剩下的，给一句点评和一个下次能照做的替换。估得不对可以点「估高了 / 估低了」，Claude 会重估并记住这道菜的分量
- **训练**：按计划逐组记重量和次数。Claude 和前几次比，给出每个动作下次的具体重量和次数，网页记录时直接当默认值
- **身体和恢复**：体重、腰围、睡眠、喝水（牛奶、豆浆也算进摄入）。接了 Apple 健康后，活动多的日子自动加餐，静息心率和 HRV 偏离基线时提醒练得保守些
- **数据**：睡眠、体重、增肌（或减脂）进度、静息心率和 HRV、步数和活动、饮食、训练各一张卡，可以看 7/30/90 天的走势，和目标或自己的基线比；每张卡上有 Claude 的一句判断和一个具体做法，点「这是什么」看这个数的意思。每个动作有进步曲线（估算的最大重量）。周报做成一页：本周和上周对比、各项做到了几天、下周重点
- **Claude 页**（右上角 ✦）：你的私人教练住在这里。最需要你做的放最上面：Claude 的计划提案（点「同意」就改）、要写进训记的模版（点「写进训记」就写）、它问你的问题；你可以给它留话（"这周出差只能练 3 天"），它下次处理时照办并回复；它做过的事都有记录，自己做主的小调整可以一键撤回；「Claude 记得的」列出它记住的关于你的事，能改能删；日报、周报、计划说明也在这里
- **授权**：Claude 能自己做主到什么程度由你定：小调整（按规则加减计划重量、热量一次 ±150 以内）直接改、事后告诉你，或者什么都先问你。「今日」页最上面是 Claude 的简报：这天的判断、接下来做什么、有什么等你拍板
- **计划**：按基础信息算热量和三大营养素目标，排训练分化；按体重趋势和执行情况调整。目标可以选减脂、增肌、薄肌（体脂低、有线条、不追求大块）、减脂增肌、力量、健康
- **五件套**：「今日」页一条「大水 · 大睡 · 大蛋 · 大站 · 薄肌」，用已经记的喝水、睡眠、蛋白质、步数和训练自动算，不用另外打卡
- **自己说了算**：目标、休息日目标、喝水目标、训练日（动作、组数、次数、轮换顺序）、快捷清单都能自己改（训练日在「训练」页，饮食目标在「今日 → 摄入 → 目标」），Claude 之后照你的来，只提建议不覆盖；一餐知道热量可以直接填；同步来的睡眠、体重错了可以改或清除，没戴表的日子可以标「不算」；「今天要做的」可以自己加、也可以划掉 Claude 的某条；一天从几点算起、提醒、深浅色、休息计时器在「偏好设置」里按人设置
- **Apple 健康同步**：iPhone 快捷指令把健康数据传上来，用每人自己生成的只能上传的令牌。戴着 Apple Watch 练（在手表上开「传统力量训练」）的话，练完同步一次，「训练中」记的那次训练上就有平均、最高心率和消耗
- **训记（可选）**：如果你用训记记训练，练完网页上点一下就能把训练导进来；计划可以写成训记的模版，在网页上确认后直接写进训记，「训练」页上每个训练日都对应着训记里的训练，见下文

## 隐私

先把这几点想清楚再用：

- **Claude 处理时，照片和记录会发给 Anthropic。** 分析在你电脑上的 Claude Code 里进行，它把要分析的照片和文字发给 Anthropic 的模型。服务器本身只在你点「从训记同步」「写进训记」时连训记，不连其他外部服务
- **CLI 令牌（`LSJ_TOKEN`）能读写所有账号的数据。** 谁拿着它（就是运行 Claude Code 的人），谁就能看到每个人的全部记录和照片。它不能建账号、改密码
- **管理员在网页上看不到别人的记录，但这不是隐私边界。** 管理员可以重置任何人的密码，再用新密码登录他的账号；服务器的 root 能看到一切
- 健康同步用的上传令牌只能上传，读不到任何数据；数据库里只存它的哈希
- 「同步健康」快捷指令每次会传最近两天的心率和活动能量明细（带每个样本的来源设备名）。服务器只用它算「训练中」记的每次训练的平均、最高、最低心率和消耗，存这几个数，不存原始明细
- 数据没有加密存储；备份默认和数据在同一块盘上

所以：只和你信任、也信任你的人共用一台服务器。详细的威胁模型见 [SECURITY.md](SECURITY.md)。

## 快速开始

### 1. 在本机试一下

需要 Python 3.9+，不用装任何依赖。

```sh
LSJ_TOKEN=dev-token LSJ_PASSWORD=dev-password LSJ_DATA=./data LSJ_COOKIE_SECURE=0 python3 app/server.py
```

打开 http://127.0.0.1:8780 ，用 `admin` / `dev-password` 登录。`LSJ_COOKIE_SECURE=0` 只用于本机 http 测试。

### 2. 部署到服务器

一台 Linux 服务器 + systemd + nginx + HTTPS 证书，步骤见 [deploy/README.md](deploy/README.md)（也有 Docker Compose 的写法）。环境变量见 [.env.example](.env.example)。

### 3. 接上 Claude Code

1. 在你的电脑上装好 [Claude Code](https://claude.com/claude-code)，克隆这个仓库
2. 按 [docs/config.example.json](docs/config.example.json) 写 `~/.config/lianshiji/config.json`（服务器地址和 `LSJ_TOKEN`），`chmod 600`
3. `bin/lsj users` 看能不能连上
4. 在仓库目录里运行 `claude`：
   - `/fitness-plan`：按基础信息做计划（先在网页「我的 → 基础信息」填好）
   - `/fitness-review`：处理新记录、写日报；新的一周第一次运行时顺便写上周的周报。参数 `weekly` 强制写周报
   - 想让它定时自己处理：用 `scripts/auto-review.sh` 和 launchd（模板 `deploy/auto-review.plist.example`，里面有安装命令）。定时运行不直接改计划，计划改动都做成提案等你在网页上同意；有事要做时才启动 Claude，会用到你的 Claude 额度
5. 只属于你自己的说明（服务器地址、SSH、你的作息习惯）写进仓库根目录的 `CLAUDE.local.md`，它不进仓库，Claude Code 会自动读

Claude 怎么读写数据、数据长什么样，见 [CLAUDE.md](CLAUDE.md) 和 [docs/data-model.md](docs/data-model.md)；处理流程在 `.claude/skills/` 里。

### 4. iPhone 快捷指令

在一台登录了 iCloud 的 Mac 上：

```sh
deploy/make-shortcut.py https://你的域名
deploy/deploy.sh
```

用户在网页「我的 → Apple 健康同步」下载快捷指令、生成自己的上传令牌，粘进快捷指令的第一个文本框。可以在「快捷指令 → 自动化」里设成每天早上自动跑。

## 训记（可选）

训记是一款记训练的 App。连上之后，训记里的训练会同步进薄肌研究所，由 Claude 点评；也可以把计划写成训记的「Agent 模版」，打开训记就能照着练（每次写入都会先给你看、等你同意）。

- 这是**非官方**的对接，用训记开放的接口，需要你自己在训记 App 里申请 key
- key 存在 `~/.config/lianshiji/xunji.json`，格式见 `bin/xunji -h`
- 想在网页上点一下就导入（不用等 Claude 处理）：在「我的 → 训记」里存训练 key（只能读）。存在服务器的数据库里，只在你点「从训记同步」时用，导入最近 3 天，不会删任何记录
- 想在网页上确认后直接写进训记：再存模版 key（只能改训记里「Agent 模版」这一个文件夹）。Claude 准备好模版后在 Claude 页（右上角 ✦）列出每个模版的动作、组数和重量，你点「写进训记」服务器才提交
- 用示例 systemd 服务文件的话，要删掉里面禁止外网的两行（见 `deploy/README.md`）
- 用法和规则见 [CLAUDE.md](CLAUDE.md) 的「训记」一节

## 开发

```sh
python3 -m unittest discover -s tests -v   # 测试
ruff check .                                # 代码检查（ruff.toml）
scripts/check-secrets.sh                    # 提交前检查有没有密钥、IP 之类的个人信息
```

没有构建步骤，服务端和命令行只用标准库。见 [CONTRIBUTING.md](CONTRIBUTING.md)。

代码、命令和路径里的 `lsj`、`lianshiji` 来自项目原来的名字「练食记」。

## 限制

- 界面只有中文
- 单进程 + SQLite，适合一家人、几个朋友，不适合大规模
- 热量是照片估的，有误差；不是医疗建议
- 只有 IP 没有域名时，要用 Let's Encrypt 的短期 IP 证书，必须自动续期
